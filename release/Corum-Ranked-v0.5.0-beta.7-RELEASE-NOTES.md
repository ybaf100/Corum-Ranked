# Corum Ranked v0.5.0-beta.7

## 변경 사항

- Round/Death Match 준비 10초가 시작되는 즉시 서버가 선택한 정확한 Geometry Dash 레벨 ID를 조회합니다.
- 서버 메타데이터로 임시 `GJGameLevel` 객체를 만들던 경로를 제거했습니다. 저장된 실제 레벨 또는 Geometry Dash의 정확한 온라인 검색 결과만 실제 `LevelInfoLayer`에 전달합니다.
- 실제 레벨 객체가 준비되는 즉시 실제 레벨 창을 미리 열어, Geometry Dash의 바닐라 맵 업데이트·다운로드와 음원 준비를 바로 시작합니다.
- 카운트다운의 첫 5초에는 맵 이름·제작자·현재 준비 단계·전체 준비 진행률을 보여주는 전체 화면 창을 표시합니다.
- 남은 시간이 5초가 되면 준비 창이 부드럽게 사라지고 실제 Geometry Dash 레벨 창이 드러납니다. 조회가 늦게 끝난 경우에는 실제 창이 준비되는 즉시 표시됩니다.
- 진행률은 네트워크 바이트 수가 아니라 `정확한 레벨 조회 → 맵 준비 → 음원 준비 → Ready/상대 대기 → 시작`의 전체 준비 상태를 나타냅니다. 각 단계는 실제 완료 신호를 받기 전까지 다음 구간으로 넘어가지 않습니다.
- 실제 Geometry Dash Play 버튼을 통한 자동 입장, 서버 권위 Ready/PLAYING 전환, 0초의 선택적 무음 시작, 기존 경기·점수·LP/MMR 규칙은 유지됩니다.

## 적용

패치 ZIP은 상위 감싸기 폴더가 없습니다. 프로젝트 최상위에서 압축을 풀어 동일 경로의 파일을 덮어쓴 뒤 서버와 클라이언트를 함께 beta.7로 빌드합니다.
