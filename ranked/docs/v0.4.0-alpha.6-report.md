# v0.4.0-alpha.6 수정 보고서

## 목적

alpha.5 최초 Render 배포 과정에서 확인된 client server URL 설정 문제와 CI의 stale Debug Bot
test naming 문제를 한 번에 정리한다. Corum Integration runtime/source는 수정하지 않는다.

## 반영 내용

1. `hwanhee1.corum_ranked`의 기본 production server URL을
   `https://corum-ranked.onrender.com`으로 설정했다.
2. 저장된 `ranked-server-url` 값이 빈 문자열이면 C++ runtime도 같은 기본 URL로 fallback한다.
3. Debug Bot server API 이름은 `DebugBotService` / `debugBot`으로 통일했다.
4. 기존 working tree에 남을 수 있는 `test/debug-bot-flow.integration.test.ts`를 alpha.6 canonical
   API를 검증하는 smoke test로 제공해 overlay 설치 시 stale typecheck 오류를 덮어쓴다.
5. Render production build command는 `npm ci --include=dev && npm run build`로 문서화했다.
6. client/server/rules/package-lock version을 `v0.4.0-alpha.6` / `0.4.0-alpha.6`으로 맞췄다.

## 검증 명령

```bash
cd ranked
npm ci --include=dev
npm run typecheck
npm test
npm run build
npm run test:harness
```

Apps Script compatibility 검증:

```bash
node apps-script/validate-ranked-config.mjs
node apps-script/validate-record-sheet-compat.mjs
```

Geode mod는 GitHub Actions `build-ranked-mod.yml`의 Windows/iOS/Android32/Android64 matrix로
최종 확인한다.
