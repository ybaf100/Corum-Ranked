# Corum Ranked v0.5.0-beta.1 report

## Rating model

- Hidden MMR is seeded from CSMP and remains server-only.
- Visible LP stays at 0 and is omitted from responses until placement is complete.
- Placement results are ordered `WIN`/`LOSS` marks. The last placement copies rounded MMR to LP, except an inclusive ±15 cutoff zone is moved down to cutoff-16. Placement completion bypasses promotion.
- Regular LP uses a 25-point base with a clamped MMR/LP correction factor from 0.5 to 1.5.
- Promotion starts at cutoff-1 without counting the trigger match. Series length and required wins come from the source-tier Spreadsheet row. Success gives cutoff+50; failure gives cutoff-50.
- A loss that reaches a tier floor is protected. MMR below that floor enables `DEMOTION WARNING`; the next decisive loss demotes to floor-50. MMR at/above the floor keeps LP protected without a warning.
- Hidden MMR uses Elo plus bounded Score margin, Clear margin, and streak factors. A winner that trails in either total Score or Clears receives reduced MMR movement.

## Client presentation

- Placement and promotion use colored `O/X/-` tracks in both lobby and result; a five-game placement therefore appears as `UNRANKED - O----` after its first win, never as remaining-game text or `0 LP`.
- Final placement renders `<TIER> - <LP> LP` with green `PLACED`.
- LP changes show the prior LP, move/fade the signed delta into it, and fade in the authoritative next LP.
- Promotion cards add fire particles; lobby and result cards show 2x+ win/loss streak labels.
- Match and result audio switches start in the same update tick. Match music remains active through the LevelInfo countdown and stops only when vanilla PlayLayer initializes.

## Start-loop diagnosis and fix

The supplied log reached `ROUND_PLAYING` and repeatedly logged that the LevelInfo Play activation did not leave the scene. alpha.40 selected the first `CCMenuItem` in `m_playBtnMenu`; child order is not stable across platforms and NONG/UI mods. beta.1 resolves the item containing Geometry Dash's native `m_playSprite`, uses a selector proxy only when identity lookup is unavailable, keeps retries bounded, and preserves one authoritative attempt-start timestamp across watchdog retries.

## Deployment

1. Replace/redeploy `apps-script/RankedConfig.gs` and run `setupCorumRankedConfig()` once. Fill the new promotion columns and LP/MMR config rows, then validate before enabling queue.
2. Apply `ranked/migrations/0005_v050_rating_system.sql` to the alpha.40 database before starting the beta server.
3. Deploy server and client together; the exact required client is `v0.5.0-beta.1`.
4. Official client builds keep `CORUM_RANKED_DEBUG_BOT_MATCH=OFF`; the Debug Bot and Force Win/Lose implementation files are not linked into that binary. Enable both client and server debug settings only in a development environment.
