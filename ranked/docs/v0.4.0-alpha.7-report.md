# Corum Ranked v0.4.0-alpha.7 implementation report

## Active-mod allowlist policy

Ranked allowlist enforcement now applies to active user mods only. A mod is active when the client snapshot reports both `enabled=true` and `loaded=true`. Installed-but-disabled mods are ignored for unauthorized-mod and version checks. Required allowlisted mods must be active.

The client avoids sending inactive user mods to the server. CBF is a special mandatory dependency: an inactive CBF snapshot may be retained so the UI/server can distinguish an installed-but-inactive CBF from a missing CBF.

The shared server rules also filter the submitted environment to active mods before allowlist evaluation, preventing older clients that still submit disabled mods from causing false blocks.
