# Corum Ranked v0.4.0-alpha.13

## Fixes

- LAST ATTEMPT is a start-deadline, not an attempt-end deadline. `ROUND_SETTLING` now preserves the accepted active attempt client-side and keeps trigger-side spectator telemetry visible until completion.
- `currentRound.scores` remains committed/authoritative. `currentRound.displayScores` adds the current active attempt's provisional score once it reaches Qualifying so the HUD visibly rises during play without mutating rating-authoritative state.
- Debug Bot default tuning is reduced: attempt delay 1200 ms; EASY 22% qualifying / 1% clear / 11% per sec; NORMAL 45% / 4% / 16% per sec; HARD 68% / 10% / 22% per sec. Environment overrides remain supported.
