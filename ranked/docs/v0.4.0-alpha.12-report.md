# Corum Ranked v0.4.0-alpha.12 implementation report

## Scope

This release is a client-side menu/resource-loading stabilization update. Ranked server rules, database schema, Apps Script configuration, and Corum Integration runtime are unchanged.

## Ranked menu scene

- The main Geometry Dash title screen now exposes Ranked through a bottom-center crossed-swords button.
- Opening Ranked pushes a dedicated scene with the existing Ranked hub/match flow rendered over the Geometry Dash gradient background.
- Closing Ranked pops back to the previous Geometry Dash scene.

## Level loading

- `GameLevelManager::getSavedLevel()` is no longer treated as proof that a level is playable.
- A Ranked map is ready only when the selected level ID matches, `m_levelString` is non-empty, and `m_levelNotDownloaded` is false.
- Automatic launch goes through `LevelInfoLayer::scene()` and `LevelInfoLayer::onPlay()` so Geometry Dash owns gameplay validation, scene setup, audio setup, and the quit/return path.
- Metadata-only downloads stay in the retry loop and remain subject to the existing 30-second map deadline.

## Song loading

- Required custom song IDs are collected from both the primary `m_songID` and 2.2 `m_songIDs` comma-separated list.
- Missing SongInfo metadata is requested with `MusicDownloadManager::getSongInfo()` before starting the custom-song download.
- Stalled SongInfo requests retry after 2 seconds; stalled song download requests retry after 3 seconds.
- The UI distinguishes `FETCHING SONG INFO...`, `DOWNLOADING...`, `DOWNLOADED`, and `START WITHOUT SONG`.
- The 20-second bypass does not cancel an already-issued Geometry Dash download.

## Unchanged rules

- Map download maximum: 30 seconds.
- Round 1 map failure: Match Canceled and unrated.
- Round 2+ / tiebreaker / deathmatch map failure: failing player loses the match.
- Song failure never cancels or forfeits a match.
- Orange text/arrows from the supplied UI sketches remain design annotations only and are not rendered in-game.
