# Corum Ranked v0.4.0-alpha.10 implementation report

## Scope

This alpha implements the supplied Ranked UI sketches and the revised resource/2-Clear rules. Orange text, arrows, and notes in the sketches are specification annotations only and are not rendered in-game. Corum Integration is unchanged.

## Client UI

- Full-screen in-game Ranked layer replaces the previous popup-style flow.
- Main Ranked screen, Match Found, private Ban Map, Round/Deathmatch preparation, Match End, Queue Again, and Match History/detail views are included.
- Match History exposes completed matches only and includes each round's map, score, and approved Clear count plus Deathmatch summaries.

## Resource preparation

- Round preparation begins with a 10-second local presentation countdown.
- If the user has not pressed a missing resource button by 5 seconds remaining, the client starts that download automatically.
- Map states: DOWNLOAD MAP -> DOWNLOADING... -> DOWNLOADED.
- Song states: DOWNLOAD SONG -> DOWNLOADING... -> DOWNLOADED; after 20 seconds the client may start without the song while Geometry Dash continues the download.
- Map download has a 30-second limit from the first download attempt. Round 1 failure reports a cancellation; later-round/deathmatch failure reports a forfeit.
- The server reserves at least 60 seconds for preparation so the client-side map/song windows can complete.

## Revised 2-Clear LAST ATTEMPT

When one side reaches 2 Clears while the opponent has 0 or 1 Clear, the opponent receives a 10-second attempt-start window. Attempts started by the deadline remain valid until they end. If a 0-Clear opponent reaches 1 Clear, the same window remains open; reaching 2 Clears produces a Draw. Otherwise the 2-Clear side wins when the window and all valid attempts settle.

## Match exit and results

When authoritative match state leaves a playable phase, the Ranked PlayLayer hook uses Geometry Dash's normal quit path so the game owns scene/audio cleanup. Match Result exposes post-match rating/tier data and round summaries; Queue Again clears match-local state but keeps the session.

## Validation

- TypeScript production source and rules source were transpile/syntax-checked with TypeScript `--noCheck` in the packaging environment.
- New Geode API calls were checked against current Geode class documentation for LevelDownloadDelegate, GameLevelManager, MusicDownloadManager, and PlayLayer.
- Full dependency-backed Vitest/typecheck and multi-platform Geode compilation remain CI gates in GitHub Actions.
