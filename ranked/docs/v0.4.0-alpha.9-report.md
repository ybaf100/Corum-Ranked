# Corum Ranked v0.4.0-alpha.9 report

## Scope

This release hardens first-session CSMP seeding against Google Apps Script cold-start latency.

## Changes

- Added `RANKED_CSMP_FETCH_TIMEOUT_MS` independently from Ranked config fetch timeout. Default: 30000ms.
- Retries `csmp` and `player_records` exactly once on timeout.
- Converts final timeout into HTTP 503 with `code=CSMP_SOURCE_TIMEOUT`.
- Converts upstream HTTP/network/invalid JSON failures into explicit 503 CSMP source errors.
- Caches the shared `csmp` tier definition for `RANKED_CONFIG_REFRESH_MS` and de-duplicates concurrent fetches.
- Keeps `player_records` per-account and uncached for first seed lookup.
- Extends only the initial client session request timeout to 70 seconds.
- Adds server tests for caching, retry, 503 mapping, and the new environment setting.
- Corum Integration is unchanged.

## Deployment

Recommended Render variables:

```text
RANKED_CONFIG_FETCH_TIMEOUT_MS=10000
RANKED_CSMP_FETCH_TIMEOUT_MS=30000
```

Existing deployments that do not set `RANKED_CSMP_FETCH_TIMEOUT_MS` use the 30000ms default.
