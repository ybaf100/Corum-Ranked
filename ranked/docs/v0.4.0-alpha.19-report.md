# Corum Ranked v0.4.0-alpha.19

## CI / build fixes

- Replaced removed `CCARRAY_FOREACH` use with Geode v5 `getChildrenExt()` iteration.
- Marked `LevelInfoLayer::onEnterTransitionDidFinish()` override explicitly.
- Restored `CorumRankedLayer::startMapDownload()` using Geometry Dash `GameLevelManager::downloadLevel(levelId, false, 0)` and the existing `LevelDownloadDelegate` callbacks.
- Corrected `match-flow.integration.test.ts` expected `ranked_attempts` row count from 7 to 8; the scenario has 3 accepted attempts in round 1 and 5 in round 2.

## Scoring rule update

- Below Qualifying: 0.
- Qualifying through 69%: integer progress.
- 70 through 99%: integer progress x1.5.
- 100% Clear: fixed 200.
- Round and Death Match totals remain the sum of all valid attempt scores.
- Server authoritative scoring and client provisional/live scoring use the same formula.

Corum Integration was not modified.
