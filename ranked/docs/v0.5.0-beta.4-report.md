# Corum Ranked v0.5.0-beta.4 report

## 구현 범위

- Hidden MMR 상대 강도 가중치와 표시 LP 상대 강도 가중치
- 서버 권위 3-Clear 무패 `PERFECT WIN` 판정
- 기존 공식 최대 MMR·LP 획득량 적용
- 결과창 노란 `PERFECT WIN`
- gameplay timer 위 현재 Round/Death Match 표시
- Hidden MMR·LP 전체 반영 요소와 수식 운영 문서
- 정확한 beta.4 클라이언트/서버 버전 gate

## 판정 경계

`PERFECT WIN`은 자연스럽게 `MATCH_RESULT`가 된 경기에서만 판정합니다. 승자는 패배 라운드가 없어야 하고, 한 번 이상의 결정승이 있어야 하며, 모든 결정승은 승자 3-Clear 뒤 상대의 LAST ATTEMPT가 끝난 `LAST_ATTEMPT_EXPIRED`여야 합니다. 무승부는 허용합니다. Force Win/Lose, ready/reconnect/resource forfeit, 일반 Score 승리, Death Match 승리는 제외합니다.

## 보상

- Hidden MMR: 해당 플레이어의 placement/regular K-factor × `(1 + scoreMarginMaxBonus + clearMarginMaxBonus)` × `(1 + streakMaxBonus)`를 설정된 반올림으로 지급합니다.
- 표시 LP: `visibleScoreBaseChange × visibleScoreMaxFactor`를 반올림한 일반 공식 최대치를 사용합니다.
- 패자 계산과 배치 공개 시점, 승급전, 강등 규칙은 변경하지 않습니다.

## 배포 메모

추가 DB migration은 없습니다. Apps Script 재배포 후 `setupCorumRankedConfig()`를 실행해 누락된 두 상대 강도 가중치 행을 추가하고 설정 검증이 성공한 뒤 서버를 배포합니다.
