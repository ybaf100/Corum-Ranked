# Corum Ranked v0.4.0-alpha.26

## Scope

This build targets four real-device regressions reported after alpha.25: Clear/score appearing and then reverting, previous-round score/Clear presentation leaking into a new round, a fake extra visual attempt after LAST/Final Attempt had already closed, and Debug Trigger Death Match occasionally remaining stuck on Loading Map. It also makes the LevelInfo Ranked banner reflect the actual round phase.

## Attempt result ordering

The first visual Attempt now snapshots its start context/time when LevelInfo arms the selected level. If polling advances the public phase while PlayLayer is being constructed, that already-legitimate visual start can still be journaled with the pre-transition timestamp instead of silently becoming a local-only attempt. Entering a brand-new PlayLayer is no longer allowed once the server is in `ROUND_SETTLING`.

`/attempt/progress` is best-effort live telemetry. A late progress response is no longer allowed to apply its snapshot once that same attempt has a queued End or the transport has advanced to another attempt. This prevents an older non-Clear snapshot from replacing a newer Clear/Attempt-End state.

## Round-scoped optimistic state

Optimistic score and Clear presentation is now derived from pending attempt journal entries that match the current context key (`matchId + roundNumber` or `matchId + deathmatchSequence`). Pending results from a previous round remain deliverable to the server but are no longer displayed in the next round.

## Final/LAST Attempt visual lifecycle

`PlayLayer::resetLevel()` now treats `ROUND_SETTLING` as a closed start window. After the currently valid attempt dies/ends, vanilla Geometry Dash reset is blocked and the player exits to Ranked result/spectator flow instead of seeing a non-authoritative extra Attempt.

## Map-entry recovery

If the client first observes `ROUND_PLAYING` or `DEATHMATCH_PLAYING` without a locally playable map (for example because a Debug scenario advanced through PREPARE between polls), Ranked now opens the real Geometry Dash LevelInfo download gate with a zero countdown. The same page downloads the map/song and auto-enters when ready.

## LevelInfo phase title

The preparation overlay now displays `ROUND 1`, `ROUND 2 - MATCH POINT`, `ROUND 3 - TIEBREAKER`, or `DEATH MATCH` according to the authoritative match state.
