# Corum Ranked v0.4.0-alpha.14

## Client hardening

- Main-menu Ranked shortcut moved to the upper-right so it no longer overlaps the vanilla bottom action row.
- Active Ranked LevelInfoLayer navigation is locked against repeated Back/key-back input, with a one-shot return guard for scene-stack recovery.
- Song preparation now kicks Geometry Dash's own CustomSongWidget download action and uses direct MusicDownloadManager requests only as fallback coverage for additional song IDs.
- After the explicit 20-second song ceiling, Ranked enters through LevelInfoLayer::playStep2 to avoid the vanilla No Song confirmation interrupting the match.
- Player icons are larger, Match Found is top-aligned, the ban phase is a five-card horizontal row, and long map names may use two lines.

## Unchanged

- Server-authoritative scoring/MMR rules, LAST ATTEMPT settling, provisional live score display, Debug Bot tuning, map timeout policy, and active-only mod allowlist remain unchanged from alpha.13.
- No Apps Script or Neon migration change.
- Corum Integration remains unchanged.
