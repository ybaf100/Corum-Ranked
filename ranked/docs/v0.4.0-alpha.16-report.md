# Corum Ranked v0.4.0-alpha.16

## Scope

This release fixes three alpha.15 live-device regressions: song preparation / no-song start, missing Corum difficulty colors, and a misleading ban-confirmation race. Corum Integration is unchanged.

## Song preparation

- `MusicDownloadManager::getSongInfo(id, true)` is used when metadata is missing so the vanilla request carries download intent.
- The direct custom-song fallback now uses `downloadCustomSong(id)` instead of `downloadSong(id)`.
- `FETCHING SONG INFO...` and `DOWNLOADING...` are derived from GD's active download keys/actions rather than from local request-attempt flags, so the Ranked UI no longer claims a download is running when the vanilla manager is idle.
- The hidden/real `CustomSongWidget::onDownload()` path remains available as the vanilla primary/re-kick path.
- After the 20-second Ranked song ceiling, the client no longer jumps directly to `LevelInfoLayer::playStep2()`. It marks the level's vanilla song warning as already acknowledged and calls the normal `LevelInfoLayer::onPlay()` path so all required GD play-state initialization still runs.
- Song timeout still never causes Match Cancel/Loss, and an in-flight download is not cancelled.

## Ban acknowledgement

The alpha.15 UI marked a map `BANNED` immediately when the player tapped the button, before the server accepted the request. A request rejected near the deadline could therefore look confirmed locally even though that map remained legal and could later be selected.

alpha.16 adds viewer-local `banStatus` to match state. During `BAN_PHASE` the server exposes only the requesting player's confirmed ban; the opponent's ban remains private. The client displays `BANNING...` while awaiting acknowledgement and only displays `BANNED` after server confirmation.

Server rules still remove confirmed canonical IDs before selecting/ordering the three Round maps. Integration coverage now asserts that a shared confirmed ban is not selected for Round 1.

## Difficulty colors

The Ranked client now contains its own Corum rating palette (without linking to Corum Integration) and applies it to both Ban candidate difficulty labels and the revealed Round/Death Match difficulty label.

## Required live-device retest

1. Press `DOWNLOAD SONG` and verify GD actually begins downloading the custom song.
2. Verify the UI changes to `DOWNLOADED` only when `MusicDownloadManager::isSongDownloaded()` reports success.
3. Let the 20-second song ceiling expire and verify `START WITHOUT SONG` enters the map without an error or No Song popup.
4. Ban a map near the 10-second deadline and verify `BANNING...` becomes `BANNED` only after server acknowledgement.
5. Confirm a server-acknowledged banned map never appears in Round 1/2/3.
6. Verify numeric Corum difficulties such as `17`, `20.1`, `21+`, etc. render using their rating colors.
