# Corum Ranked v0.4.0-alpha.17

## Scope

Client-only song-download flow correction based on `v0.4.0-alpha.16`. Ranked server rules, database schema, Apps Script config, ban resolution, scoring, Death Match, and Corum Integration are unchanged.

## Vanilla LevelInfo song gate

`DOWNLOAD SONG` no longer creates a hidden `LevelInfoLayer`, calls `CustomSongWidget::onDownload()` off-screen, or directly drives `MusicDownloadManager::getSongInfo()` / `downloadCustomSong()`.

Instead, Ranked opens the selected map's real Geometry Dash `LevelInfoLayer`. During resource preparation:

- the normal LevelInfo UI is covered,
- non-song menus are touch-disabled,
- the real vanilla `CustomSongWidget` is kept above the mask,
- Back and Play are blocked,
- only Geometry Dash's own song-download control remains usable,
- the Ranked preparation countdown remains visible,
- when the song is downloaded, Ranked submits Ready after the countdown,
- after 20 seconds, song availability is bypassed without cancelling any vanilla background download,
- when the authoritative server enters the playing state, the same initialized `LevelInfoLayer` enters gameplay through the normal `onPlay()` path.

At the automatic 5-second resource point, Ranked opens this song-only LevelInfo gate instead of invoking a hidden downloader. This deliberately removes the crash-prone direct download calls from alpha.16.

## Start without song

The 20-second song timeout is now handled inside the real on-screen `LevelInfoLayer`. If the song is still missing, Ranked marks the vanilla missing-song warning as already acknowledged only immediately before the normal `LevelInfoLayer::onPlay()` call. The layer has completed its normal Geometry Dash lifecycle before this occurs.

## Preserved alpha.16 fixes

- confirmed-ban UI and server-side selected-map ban regression coverage,
- difficulty-specific colors on Ban and revealed-map difficulty labels,
- decimal scoring / attempt FIFO / LAST ATTEMPT / Death Match work from alpha.15.
