# Corum Ranked v0.4.0-alpha.29

## Scope
- Config-driven Ranked audio presentation
- Ranked resource acquisition gate
- UI/audio fade transition system

## Config
`Ranked Config` now supports optional Geometry Dash custom Song IDs for the Ranked menu/queue, match flow, win result, and lose result. Each track has its own `startSeconds` value. Audio and UI fade durations are also server-configured.

Audio defaults to disabled. Existing deployments therefore retain alpha.28 behavior until `rankedAudioEnabled` is set to `TRUE` and at least one valid Song ID is configured. Missing rows are appended by `setupCorumRankedConfig()` without overwriting existing values.

## Resources
When Ranked audio is enabled, the client checks the configured Song IDs against Geometry Dash's `MusicDownloadManager`. If every configured resource is already present, Ranked opens normally. Otherwise the client shows `RANKED RESOURCES` and a single `DOWNLOAD ALL` action.

Downloads are sequential, already-present IDs are skipped, duplicate Song IDs are downloaded only once, progress is displayed, and a per-resource timeout moves failures to `RETRY FAILED`. The normal Ranked UI is unlocked only after all configured resources are ready and the user presses `CONTINUE`.

The resource screen intentionally uses only generic `RESOURCES` wording. Round-map song acquisition remains the existing vanilla LevelInfo flow and is not merged into this resource gate.

## Audio transitions
Main/Queue uses the menu resource. Match Found/Ban/Prepare/Spectator uses the match resource, falling back to the menu resource when needed. Match Result uses the configured win/lose resource with match/menu fallback. Switching tracks fades the current main music channel out and the next Ranked track in. Reusing the same configured resource across states does not restart it.

Before Ranked opens the real LevelInfo/gameplay flow, Ranked audio fades out. Leaving Ranked restores Geometry Dash menu music. Configured `startSeconds` is applied after `playMusic` using the main music channel seek API.

## UI transitions
Ranked phase/page/resource-state changes now fade the current UI out, rebuild the latest authoritative state, and fade the new UI in. If multiple server states arrive during a fade, the newest presentation key wins, avoiding stale transition callbacks. Gameplay HUD behavior is unchanged.

## Gameplay isolation
No scoring, MMR, ban, Death Match, FINAL/LAST ATTEMPT, anti-cheat, or attempt-transport rule was intentionally changed in alpha.29.
