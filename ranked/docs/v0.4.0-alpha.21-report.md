# Corum Ranked v0.4.0-alpha.21

## Purpose

alpha.21 removes the separate Ranked prepare-screen map downloader and moves resource preparation onto the real Geometry Dash `LevelInfoLayer`.

## LevelInfo preparation flow

When the server reveals a Round or Death Match map, the client immediately opens that map's normal GD level page. If no saved level object exists yet, Ranked creates only an online-level shell containing the server-selected level ID/title/creator so `LevelInfoLayer` can own the normal download flow.

During preparation:

- `LevelInfoLayer::downloadLevel()` performs the map download. Ranked no longer directly calls `GameLevelManager::downloadLevel()` from `RankedPopup`.
- The normal LevelInfo page remains visible.
- All LevelInfo menus are disabled except the real vanilla song-download widget.
- Play and Back are blocked until the server starts the round.
- A Ranked `STARTS IN...` countdown and preparation status are drawn on the LevelInfo page.
- If the vanilla map download callback disappears, a 5-second watchdog lets LevelInfo retry its own download.
- Existing map failure policy remains 30 seconds.
- Once the map payload is ready, the normal GD song widget remains the only allowed interactive control.
- Song availability remains non-fatal after the existing 20-second grace period.
- When both clients are ready and the server enters the playing state, Ranked calls the normal `LevelInfoLayer::onPlay()` from the same on-screen page so GD owns loading/audio/scene-stack behavior.

## Removed conflicting path

`CorumRankedLayer` no longer implements `LevelDownloadDelegate` and no longer owns a parallel `GameLevelManager::downloadLevel()` request. This avoids competing with the LevelInfo page for the single global level-download delegate.

## Preserved behavior

- alpha.20 scoring/attempt reliability fixes remain unchanged.
- Current scoring remains: below Qualifying = 0, Qualifying-69 = integer progress, 70-99 = integer progress x1.5, Clear = 200.
- Round/Death Match prepare side numbers remain Bo3 round wins rather than map points.
- Death Match remains exactly three attempts per player.
- Corum Integration and Apps Script are unchanged.

## Validation scope

The source tree/package structure and pure Ranked domain tests are intended to remain unchanged except for version metadata. Full Geode Windows/Android/iOS compilation and real-device LevelInfo download behavior must be confirmed through GitHub Actions and device testing.
