# Corum Ranked v0.4.0-alpha.28

## Scope
- FINAL/LAST ATTEMPT natural-completion guarantee
- result reconciliation deadlock removal
- Neon/Render database-pool resilience

## Final-attempt guarantee
The 10-second FINAL/LAST ATTEMPT value remains a **start deadline only**. A visual attempt that starts before the deadline is never force-ended because a transport lease aged out. Late packet reconciliation remains bounded to 5 seconds, while a start-intent that was received in time no longer expires after 30 seconds merely because the authoritative Start FIFO is still catching up.

A valid pending intent remains alive while the match connection remains alive. Active Round and Death Match attempts are no longer invalidated by an absolute `orphanAttemptSeconds` lifetime; disconnect/recovery policy is responsible for abandoned clients.

## Client defense
PlayLayer no longer calls `onQuit()` on a still-alive attempt just because a stale poll reaches a result state. After the attempt naturally dies/Clears, no new vanilla reset is allowed when the authoritative state forbids another start.

## Result reconciliation
`MATCH_RESULT` is immutable. Completed packets left only because an ACK was lost are discarded once the authoritative result is known, instead of trapping the UI forever on `SYNCING RESULT`. An actually-open visual attempt is never discarded by this cleanup path.

## Database stability
The pg Pool now has an idle-client error listener and bounded pool settings. Neon pooled-connection termination is logged instead of becoming an unhandled Node `error` event that kills the Render process.
