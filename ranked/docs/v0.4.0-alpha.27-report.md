# Corum Ranked v0.4.0-alpha.27

## Scope
- FINAL/LAST ATTEMPT start-deadline reliability
- active-attempt preservation after deadline
- out-of-map live spectator wait state

## Rule guarantee
The 10-second FINAL/LAST ATTEMPT window is a start deadline only. Any valid attempt that started before the deadline may finish naturally after it. No fourth/extra attempt is granted by this transport recovery.

## Transport change
The client sends a lightweight `/attempt/intent` signal immediately for FINAL/LAST ATTEMPT starts. The authoritative Start/End FIFO remains unchanged. The intent only keeps the round from finalizing while the real serialized Start packet catches up.

## UI
When the local player's last valid attempt ends first and the opponent still has an active attempt, the Ranked scene shows live opponent progress until the round resolves.
