# 도전과제 표현 및 번역 — beta.92

기준 main: `86ca2b2c86f5de50bef0401f8e5fe8f312699bc7` (beta.91).
beta.90의 46종 도전과제, 서버 판정/Claim Ledger, beta.91 Debug 보상 정책을 유지합니다.
새 DB migration이나 추가 기록 초기화는 없습니다.

## 카드와 칭호

단일형 카드는 미획득이어도 희귀도 색을 표시합니다. 미획득 칭호/Claim은 계속 잠깁니다.
성장형 카드의 테두리·이름·설명·수치·바는 해당 도전과제 칭호를 장착했다면 그 단계,
장착하지 않았다면 최고 달성 단계의 색을 사용합니다. 다른 도전과제의 칭호는 영향을
주지 않습니다. 진행도와 임계값은 실제 서버 기록을 유지합니다.

I/Common `#B2BAC9`, II/Rare `#57BBFF`, III/Epic `#C679FF`, IV/Legendary `#FFB046`,
V/Mythic 카드 표면 `#E5E4E2`(백금색). 금색 반짝임/파스텔 흐름은 해금된 도전과제 이름과
장착 칭호의 이름에만 적용합니다. 카드 테두리·희귀도·수치·바·단계 선택 버튼·모두 받기
배경에는 애니메이션을 적용하지 않습니다. 미획득 단일형 이름은 정적인 희귀도 색입니다.

## 모두 받기

선택한 탭과 무관하게 `scope: ALL`을 전송합니다. 모든 카테고리의 실제 미수령 Unlock에서
AP 합계와 최고 등급을 구합니다. 완료 알림/모달을 띄우지 않고 서버 응답을 반영한 뒤
도전과제를 다시 조회합니다. 중복 요청 차단, 세션 세대 검사, 단건 Claim, 서버 트랜잭션과
Ledger의 멱등성은 유지합니다.

## 시상식 후광

기존 골드 티어 ambient 자산과 자식 pulse/rotation을 재사용합니다. 3→2→1 단상/아이콘
등장 후 1등 후광은 0.55초 smoothstep으로 Fade In합니다. 기존 RGBA 루트의 cascade opacity로
제어하므로 원본 이미지의 투명도나 빛의 pulse를 덮어쓰지 않습니다. 정산 응답으로 UI가
갱신되어도 동일 시상식의 경과 시간을 유지하여 Fade In을 다시 시작하지 않습니다.

## 번역

편집 경로와 빌드 절차는 [번역 README](../translations/README.md)에 있습니다.
615개 UI/도전과제 키가 동일한 UTF-8 카탈로그에서 생성됩니다. 기존 한국어 분기와
문자열 결합 안내도 템플릿/카탈로그로 이전했습니다. 원격 사용자·레벨·곡 메타데이터는
번역 문구로 취급하지 않습니다. 누락된 미래 서버 오류는 영어 원문을 유지합니다.

## 검증 범위

색상/장착 단계/ALL 수령/후광 Fade In의 회귀를 수정 전 실패 테스트로 추가했습니다.
네이티브 카탈로그 lookup 전체, 실제 파일 수정 후 클라이언트/서버 재생성, 잘못된
자리표시자·누락 언어·중복 키 거부, 모든 활성 폰트의 글리프를 자동 검증합니다.
실제 iPadOS의 터치와 후광/문자 렌더링은 별도 실기기 QA 항목입니다.
