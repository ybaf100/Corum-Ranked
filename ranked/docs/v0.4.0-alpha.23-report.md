# Corum Ranked v0.4.0-alpha.23

## Competitive UI pass

The Ranked client UI was rebuilt around a common native Cocos/Geode visual language: deep navy panels, cyan/blue neon accents, tier-coloured player cards, stronger hierarchy, and compact status plates. The implementation uses live nodes and Geometry Dash resources rather than image screenshots so scaling and interaction remain native across Windows, Android, and iOS.

### Match Found / Ban

- Match Found uses a central countdown plate instead of loose text.
- Ban phase uses five consistent neon candidate cards, each with a map emblem, title, difficulty badge, and Ban action.
- The ban deadline is presented in a dedicated `TIME LEFT` badge.
- Private-ban status is presented in a bottom information plate.

### Round / Death Match prepare

- Player cards now use tier-coloured accent frames, icon halos, identity strips, and separate tier/LP plates.
- Bo3 round wins are shown as a compact `SERIES A : B` plate. They are never displayed as the map's accumulated score.
- Death Match attempt usage remains a separate `A n/3 | B n/3` tracker.
- Revealed map name, Corum difficulty, resource readiness, and attempt/countdown state occupy the centre column with consistent spacing.

### Geometry Dash LevelInfo prepare gate

The real Geometry Dash `LevelInfoLayer` remains the download surface. Alpha.23 replaces the loose Ranked text overlay with a compact `RANKED MATCH` panel containing countdown and resource status. The vanilla CustomSongWidget remains the actual song-download UI and the alpha.22 interaction gate remains in place.

## Scope

No Corum Integration or Apps Script changes are required. No external runtime/font service is required.
