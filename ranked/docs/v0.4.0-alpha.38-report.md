# Corum Ranked v0.4.0-alpha.38 report

## Scope

alpha.38 is a client reliability release for iOS input-object lifetime, stale polling responses, and the LevelInfo-to-PlayLayer round launch transition. It does not change Ranked rules or the database schema.

## 1. iOS touch-release crash

The three alpha.35/alpha.37 crash reports share the same native stack fingerprint:

`CCTouchDispatcher::touches -> CCEGLViewProtocol::handleTouchesEnd`

`CorumRankedLayer::refresh()` ran every 200 ms, and `prepareUiTransition()` previously returned `true` even when the presentation key had not changed. Every refresh then removed all `CCMenu` children. On iOS, Geode's selected-item cleanup hook is not installed, so `CCMenu::m_pSelectedItem` could still point at a freed button when touch-end arrived.

alpha.38:

- does not rebuild the UI when its presentation key is unchanged;
- updates countdowns, download progress, queue status, and spectator values in place;
- explicitly unselects and clears `m_pSelectedItem` before structural menu cleanup;
- disables the Ranked refresh, keypad delegate, and touch dispatcher before scene exit.

## 2. Stale match response after Queue Again

`dismissMatch()` previously cleared the token and match view without invalidating an in-flight `m_pollRequest`. Its callback could still parse the old terminal snapshot after Queue Again had begun.

alpha.38 assigns every queue/match poll a monotonically increasing generation. Cancellation, dismissal, re-queue, leave-queue, and session initialization invalidate the previous generation. A callback must match both the current generation and current match ID before it can mutate runtime state.

## 3. Round launch after Ready

The supplied runtime log proves the Ready request was accepted and authority advanced from `ROUND_PREPARE` to `ROUND_PLAYING`. The client then repeatedly armed gameplay, called `LevelInfoLayer::onPlay()`, remained on the same scene, and retried.

alpha.38 no longer treats a call to `onPlay()` as an attempted launch that needs a watchdog. It resolves Geometry Dash's canonical saved `GJGameLevel` payload, arms the authoritative Ranked context, constructs `PlayLayer::scene(level, false, false)` once, and replaces the LevelInfo scene only when construction succeeds. `PlayLayer::init` therefore becomes the synchronous launch success boundary.

## 4. Deployment and compatibility

- Client manifest: `v0.4.0-alpha.38`
- Required server client gate: `v0.4.0-alpha.38`
- Database migration: none
- Apps Script change: none
- Scoring/MMR/RP/map-pool/ban/attempt rules: unchanged

The server version gate and client must be deployed together. An alpha.38 client is intentionally rejected by an alpha.37 gate, and vice versa.
