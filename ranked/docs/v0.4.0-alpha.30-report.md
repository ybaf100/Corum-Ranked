# Corum Ranked v0.4.0-alpha.30 report

## Scope

Client-only Ranked audio resource downloader fix. Server-authoritative gameplay, scoring, MMR, bans, Death Match, FINAL/LAST ATTEMPT and attempt FIFO behavior are unchanged.

## Root cause

alpha.29 called `MusicDownloadManager::downloadSong(songId)` directly for Config-only lobby BGM IDs. That path is not reliable when Geometry Dash has not already populated the corresponding `SongInfoObject` / download URL.

## Fix

The Ranked client now requests `getGJSongInfo.php` itself, extracts the song URL, downloads sequentially with Geode `WebRequest`, and stores the result under the mod save directory. Existing GD-downloaded songs remain preferred/reused.
