# Corum Ranked v0.4.0-alpha.25

## Scope

This build focuses on two regressions observed on real devices: opaque black UI rectangles introduced by the alpha.24 panel treatment, and human-side attempt results that could remain local while the authoritative result showed 0 score / 0 clears.

## Client transport changes

- `PendingStart` stores a synchronized `clientStartedAt` timestamp.
- `PendingEnd` stores a synchronized `clientEndedAt` timestamp.
- Start/End journal entries survive public state transitions until ACK, duplicate acknowledgement, or explicit rejection.
- Spectator activation no longer clears already-observed attempt transport.
- Automatic PlayLayer exit journals an outstanding visual attempt before leaving the scene.
- Result dismissal and Queue Again are blocked while attempt transport is still pending.

## Server timing changes

A bounded 2-second transport-reconciliation grace is used only after the real attempt-start deadline. It does not extend the gameplay window. A client timestamp is considered only when it is not in the future and is no more than 2 seconds older than server receipt time. The domain rules still require that the effective start timestamp be before the actual Final/LAST Attempt deadline.

## UI changes

Stretched base-game Scale9 rectangles were removed from Ranked panels and replaced with deterministic solid-color layers and narrow accent borders. The gameplay HUD was reduced so Geometry Dash's native progress bar and percentage are left unobstructed.
